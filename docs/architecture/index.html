🏛️ 1. Multi-Format Archival Ingestion

The system ingests architectural documentation from multiple formats: PDF (via pypdf), PPTX with speaker notes (via python-pptx), DOCX field notes, JPG/PNG with EXIF GPS coordinates, and ZIP archives protected with ZipSlip traversal security.

🛑 2. Human-Only Verification Mandate

By architectural mandate, AI models can extract claims but can NEVER mark them as verified. Only human researchers or verifiers with verified RBAC credentials can certify historical facts with immutable cryptographic audit logging.

📐 3. Dense Embeddings & Grounded RAG

Features 128-dimensional normalized dense text embeddings capturing Indic morphology and character n-grams. The hybrid retrieval engine scores 60% semantic cosine similarity and 40% lexical overlap, strictly refusing out-of-scope queries below threshold 0.35.

📑 4. ReportLab PDF Dossier Generation

Compiles verified claims, 7-category archival completeness scores, gap remediation tasks, and UNESCO citations into standardized multi-page downloadable PDF dossiers using ReportLab.

🔄 Ingestion Provenance Flow

Every document is hashed with SHA-256 before extraction. If a duplicate file is uploaded, the existing record is returned without re-processing, preventing archival clutter and wasted computation.

🎯 Anti-Hallucination Guardrail

Unlike conventional conversational LLMs that fabricate answers when context is missing, HeritageProof evaluates evidence chunks against a strict 0.35 threshold. If evidence is lacking, it explicitly returns INSUFFICIENT_EVIDENCE.

🗄️ Relational Integrity & Cascades

All tables inherit UUID primary keys and UTC audit timestamps from BaseModelMixin. Child tables (processing_jobs, site_media, checklist_items) enforce ON DELETE CASCADE, while evidence verifier links use ON DELETE SET NULL to preserve archival history.

📊 7-Category Completeness Checklist

The checklist_items table tracks archival coverage across: location, construction_date, elevations, materials, features, condition, and drawings.

⚡ Serverless /tmp Adaptation

On AWS Lambda / Vercel, the code root (/var/task) is strictly read-only. HeritageProof dynamically routes SQLite, temporary uploads, and generated PDF dossiers to /tmp, guaranteeing zero cold-start filesystem crashes.

🔀 Zero-Config SPA Routing

Configured frontend/vercel.json ensures that deep links and browser refreshes on any tab (e.g. /verification, /map) rewrite to /index.html, eliminating 404 routing errors.

First, our Ingestion Pipeline handles multi-format files — PDFs, presentation decks with speaker notes, DOCX field reports, and EXIF GPS photos — stamping each with a cryptographic SHA-256 hash for tamper-evident provenance.
